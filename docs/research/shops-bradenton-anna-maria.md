## Bottom line for the guide

**There is no replacement for Annie's.** For the Cortez Bridge / Longboat Pass
/ Bradenton Beach cluster the live-bait options are now Bridge Street Bait Shop
(the only one with a first-party live-bait list), Cortez Bait & Seafood (live
shrimp credible but unconfirmed), and Island Discount Tackle 4 mi north. The
county's planned Cortez Marina on the combined Annie's + Seafood Shack site is
the eventual replacement, and it is not built.

That is itself guide content: several spots in this cluster now warrant a
"buy bait before you drive in" note of the kind Weedon Island already carries.
