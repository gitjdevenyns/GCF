# Gulf Coast Fishing Guide

## Fastest way to test
Open `index.html` on a computer. Most features work immediately. The interactive map requires internet.

## Install on iPhone
A PWA must be served over HTTPS for installation and offline caching.

Easy hosting options:
1. Netlify Drop: drag this entire folder into Netlify's deploy page.
2. GitHub Pages: upload the files to a repository and enable Pages.
3. Cloudflare Pages: connect the repository or upload the folder.

Then on iPhone:
1. Open the HTTPS address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

## Included
- Light/dark mode
- Top-five local species guides
- Interactive fishing map
- Spot filters
- Catch log stored locally
- Gear and launch checklists
- Offline app shell
- Custom iPhone icon

## Regulation warning
Fishing regulations change. Always verify the current FWC rules before harvesting fish.
